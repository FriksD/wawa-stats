# WAWA 小说数据记录与统计

一个帮你自动记录小说投稿数据的浏览器插件。

它可以记录你每天的字数、章节、收益、在读人数，并生成统计图表。

---

## 第一步：安装 Tampermonkey（篡改猴）

Tampermonkey 是一个浏览器扩展，用来运行这类脚本。

### Edge 用户

1. 打开 Edge 浏览器。
2. 访问扩展商店：
   `https://microsoftedge.microsoft.com/addons/`
3. 在搜索框输入：`Tampermonkey`
4. 找到 **Tampermonkey**，点击“获取”安装。
5. 安装完成后，Edge 右上角会出现 Tampermonkey 图标。

### Chrome 用户

1. 打开 Chrome 浏览器。
2. 访问 Chrome 网上应用店：
   `https://chromewebstore.google.com/`
3. 搜索 `Tampermonkey`
4. 点击“添加至 Chrome”。
5. 安装完成后，Chrome 右上角会出现 Tampermonkey 图标。

---

## 第二步：安装本脚本

### 方法一：从 Greasy Fork 安装（推荐）

1. 打开本脚本的 Greasy Fork 页面（需要自行挂梯）。

`https://greasyfork.org/zh-CN/scripts/591889-wawa-%E5%B0%8F%E8%AF%B4%E6%95%B0%E6%8D%AE%E8%AE%B0%E5%BD%95%E4%B8%8E%E7%BB%9F%E8%AE%A1`

1. 点击绿色的 **“安装此脚本”** 按钮。
2. Tampermonkey 会弹出安装确认页面。
3. 点击 **“安装”** 按钮。
5. 安装完成。

### 方法二：从本仓库安装

1. 打开本仓库里的文件：
   `wawa-stats.user.js`
2. 点击页面右上角的 **Raw** 按钮。
3. 浏览器可能会直接弹出 Tampermonkey 安装页面。
4. 如果没有弹出，复制页面的完整代码。
5. 点击 Edge/Chrome 右上角 Tampermonkey 图标 → **管理面板**。
6. 点击 **“添加新脚本”**。
7. 删除里面的默认代码，粘贴你复制的代码。
8. 按 `Ctrl + S` 保存。
9. 安装完成。

## 第三步：打开投稿页面

1. 打开并登录：
   `https://wawawriter.com/app/submission`
2. 等页面加载完成。
3. 刷新一次页面。
4. 如果脚本生效，页面右下角会出现两个圆形按钮：
   - `📊` 打开统计
   - `📥` 立即采集

## 怎么使用

### 自动记录

- 打开投稿页后，脚本会自动记录一次当前能获取到的最新数据。
- 以后每天打开一次页面，数据就会自动积累。

### 手动采集

- 点击右下角 `📥`，可以立即采集一次。
- 如果时间太早，可能会提示你确认，因为网站数据更新有延迟。

### 查看统计

- 点击右下角 `📊`，打开统计面板。
- 默认显示所有书的全局数据。
- 也可以切换到“单书详情”，查看某一本书的历史趋势。

### 备份数据

- 在统计面板里点击 **“导出 CSV”**，可以把数据下载到电脑上保存。

## 常见问题

### 1. 没有看到右下角的按钮怎么办？

- 确认 Tampermonkey 已经启用。
- 确认已经安装本脚本。
- 刷新页面再试一次。

### 2. 打开页面后没有自动记录？

- 可能是今天的数据已经记录过了。
- 也可能是还没到网站数据更新时间，稍后再打开一次。

### 3. 数据会丢吗？

- 数据保存在浏览器本地。
- 更新脚本不会丢。
- 卸载脚本或清理浏览器数据可能会丢，建议定期导出 CSV。

### 4. 换电脑了数据还在吗？

- 不在。数据只存在当前浏览器里。
- 换电脑前请先导出 CSV 备份。
