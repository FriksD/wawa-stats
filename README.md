# WAWA 小说数据记录与统计

一个帮你自动记录小说投稿数据的浏览器插件。

它可以记录你每天的字数、章节、收益、在读人数，并生成统计图表。

---

## 第一步：安装 Tampermonkey（篡改猴）

Tampermonkey 是一个浏览器扩展，用来运行这类脚本。

### Edge 用户

1. 打开 Edge 浏览器。
2. 访问扩展商店：
   `https://microsoftedge.microsoft.com/addons/`
3. 在搜索框输入：`Tampermonkey`
4. 找到 **Tampermonkey**，点击“获取”安装。
5. 安装完成后，Edge 右上角会出现 Tampermonkey 图标。

### Chrome 用户

1. 打开 Chrome 浏览器。
2. 访问 Chrome 网上应用店：
   `https://chromewebstore.google.com/`
3. 搜索 `Tampermonkey`
4. 点击“添加至 Chrome”。
5. 安装完成后，Chrome 右上角会出现 Tampermonkey 图标。

---

## 第二步：安装本脚本

### 方法一：从 Greasy Fork 安装（推荐）

1. 打开本脚本的 Greasy Fork 页面（需要自行挂梯）。

`https://greasyfork.org/zh-CN/scripts/591889`

1. 点击绿色的 **“安装此脚本”** 按钮。
2. Tampermonkey 会弹出安装确认页面。
3. 点击 **“安装”** 按钮。
5. 安装完成。

### 方法二：从本仓库安装

1. 打开本仓库里的文件：
   `wawa-stats.user.js`
2. 点击页面右上角的 **Raw** 按钮。
3. 浏览器可能会直接弹出 Tampermonkey 安装页面。
4. 如果没有弹出，复制页面的完整代码。
5. 点击 Edge/Chrome 右上角 Tampermonkey 图标 → **管理面板**。
6. 点击 **“添加新脚本”**。
7. 删除里面的默认代码，粘贴你复制的代码。
8. 按 `Ctrl + S` 保存。
9. 安装完成。

## 第三步：打开投稿页面

1. 打开并登录：
   `https://wawawriter.com/app/submission`
2. 等页面加载完成。
3. 刷新一次页面。
4. 如果脚本生效，页面右下角会出现两个圆形按钮：
   - `📊` 打开统计
   - `📥` 立即采集

## 怎么使用

### 自动记录

- 打开投稿页后，脚本会自动记录一次当前能获取到的最新数据。
- 网站数据每天 14:00 起陆续更新，如果有书还没更新，脚本会自动在后台每隔几分钟静默补采，直到所有书都拿到最新数据，不需要你做任何操作。
- 以后每天打开一次页面，数据就会自动积累。
- 如果一本书是新签约、还没有正式收益数据，或没有在读人数（接口显示为“暂无数据”），脚本会把它保留在书籍列表并标记“暂无数据”，但不会计入数据日期、更新进度、趋势图和 CSV；等网站更新出正式数据后，会自动开始记录。

### 手动采集

- 点击右下角 `📥`，可以立即采集一次。
- 任何时间点击都可以，脚本会按每本书自己的数据日期保存，不会记错日期。

### 查看统计

- 点击右下角 `📊`，打开统计面板。
- 默认显示所有书的全局数据：收益趋势、在读趋势、累计总收益、近 7 日对比、月度统计等。
- 全局顶部汇总中“今日新增在读”只统计纯增加；有书在读下降时，会单独显示“今日在读下降”（负数；没有下降则显示 0），不会互相抵消。
- 也可以切换到“单书详情”，查看某一本书的收益和在读人数历史趋势。
- 全局表格中“暂无数据”的书会以灰色标记显示，不会影响全局统计和导出；单书详情中也会提示该书暂无正式数据。

### 备份数据

- 在统计面板里点击 **“导出 CSV”**，可以把数据下载到电脑上保存。

## 常见问题

### 1. 没有看到右下角的按钮怎么办？

- 确认 Tampermonkey 已经启用。
- 确认已经安装本脚本。
- 刷新页面再试一次。

### 2. 打开页面后没有自动记录？

- 可能是今天的数据已经记录过了。
- 网站数据每天 14:00 后才陆续更新，如果还没到时间，脚本会自动等到更新后补采，不用手动操作。

### 3. 数据会丢吗？

- 数据保存在浏览器本地。
- 更新脚本不会丢。
- 卸载脚本或清理浏览器数据可能会丢，建议定期导出 CSV。

### 4. 换电脑了数据还在吗？

- 不在。数据只存在当前浏览器里。
- 换电脑前请先导出 CSV 备份。
